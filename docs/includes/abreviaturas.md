*[ABI]: Application Binary Interface: cómo se pasan argumentos y se nombran símbolos a nivel binario
*[ADT]: Algebraic Data Type: tipo algebraico (enum con datos)
*[API]: Application Programming Interface
*[CI]: Integración continua (Continuous Integration)
*[CLI]: Command-Line Interface: programa de línea de comandos
*[CVE]: Common Vulnerabilities and Exposures: identificador público de una vulnerabilidad
*[DI]: Dependency Injection: inyección de dependencias
*[FFI]: Foreign Function Interface: llamar a código de otro lenguaje (normalmente C)
*[GC]: Garbage Collector: recolector de basura
*[JWT]: JSON Web Token
*[LTO]: Link-Time Optimization: optimización durante el enlazado
*[MPMC]: Multi-Producer, Multi-Consumer: canal con varios emisores y varios receptores
*[MSRV]: Minimum Supported Rust Version: versión mínima de Rust soportada
*[MVP]: Minimum Viable Product: producto mínimo viable
*[RAII]: Resource Acquisition Is Initialization: el recurso se libera al destruir su dueño
*[SIMD]: Single Instruction, Multiple Data: una instrucción procesa varios datos a la vez
*[SMT]: Simultaneous Multithreading: dos hilos de hardware por núcleo (Hyper-Threading en Intel)
*[TTL]: Time To Live: tiempo de vida antes de expirar
*[TUI]: Text User Interface: interfaz de usuario en la terminal
*[UB]: Undefined Behavior: comportamiento indefinido
*[Wasm]: WebAssembly
*[WASM]: WebAssembly
